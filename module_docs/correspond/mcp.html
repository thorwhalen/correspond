correspond.mcp

MCP over stdio: the same tools, for Claude Desktop and other local MCP clients.

Run correspond-mcp (install the extra first: pip install "correspond[mcp]"). Tools are named by correspond.tools:<name> reference, so the core never imports an MCP library. By default the server exposes only the tools that read (channels, requirements, capabilities, ref, read, listen). The writes (send, edit, react) are exposed only when the operator starts it with --allow-send, and every write still takes dry_run.

The data root is the server’s, never the model’s: data_dir is removed from every tool’s schema. Point the server elsewhere with CORRESPOND_DATA_DIR in the client configuration:

{"mcpServers": {"correspond": {"command": "correspond-mcp"}}}
